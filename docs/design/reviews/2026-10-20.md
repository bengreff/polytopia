# Adversarial review — 2026-10-20 (design v4 → v5)

Four independent reviewers: ML architecture, rules/domain, systems/compute, strategy/plan.
This records each major finding and what was done with it.

| # | Finding (reviewer) | Severity | Disposition |
|---|---|---|---|
| 1 | Fog model wrong: explored tiles show live contents; only invisible units, unexplored tiles and stars are hidden (rules; confirmed via `TileData.GetUnit(..., includeHidden=false)`) | critical | **Accepted.** scope-and-rules corrected; belief, encoder and fog-leak test rescoped |
| 2 | Canonical ordering unsafe: building adjacency → level-ups, road/port connections, tech prerequisites, lighthouse, monuments, Giant pushes (rules) | critical | **Accepted.** Hand-written ordering dropped; canonical-hash dedup only |
| 3 | Action space missing commands (Recover, Promote, ExamineRuins, Destroy, Harvest, Hide, embassies, peace, Disembark, …) (rules) | critical | **Accepted.** Policy is now a pointer over the game's legal-command list, plus a coverage test |
| 4 | Cost model off by 10×+: clone via deserialize, legal-move generation unpriced, GC; critical-turn budget ~200× (systems, ML) | critical | **Accepted.** Cost table rebuilt; heavy search moved to play time; M0 measures end-to-end |
| 5 | Milestone 1 was the whole planner (strategy) | critical | **Accepted.** M1 = BC policy, no search; M2 = turn sampler |
| 6 | No guards against Polyfish-style silent bugs (strategy) | critical | **Accepted.** CI suite added: loud evaluator, parity, canary, smoke test, built-state validity |
| 7 | Planning on the mode of a factorized belief gives an empty fog (ML) | critical | **Accepted.** Joint count-then-place sampler; pessimistic capital safety; no mode-planning |
| 8 | Gates statistically unpassable (all three) | critical/major | **Accepted.** Wilson pooled lower bound + 70% per-cell floor; SPRT or EMA without gating |
| 9 | Random-number leak: ruin rewards and explorer paths from the state's seed (ML, rules, systems) | major | **Accepted.** Reseed every determinization; seed added to the fog-leak test |
| 10 | Plan-level selection: length bias, undefined prior after merging, Gumbel guarantee lost (ML) | major | **Accepted.** Per-decision Gumbel search with rollout completion |
| 11 | Value targets too noisy for pruning (ML) | major | **Accepted.** TD(λ)/bootstrapped targets, per-game down-weighting, reanalysis, aux heads carry more |
| 12 | Expert iteration vs PPO decided before measurement; search multiplies simulator steps (ML, strategy) | major | **Accepted.** M3 A/B at equal simulator time; expert iteration needs ≥ 50 Elo; Ben signs off |
| 13 | Topology backwards: run inference on the 4070 Super; Mac = actors only (systems, ML) | major | **Accepted.** |
| 14 | No x86 libraries in the APK; native Steam builds at build 16375 would be the biggest throughput gain (systems) | major | **Accepted.** 2-day spike in M0 |
| 15 | Deterministic argmax play is exploitable; no real magnet (ML) | major | **Accepted.** Sample at play time; KL to a slow EMA magnet + uniform |
| 16 | Crazy is +3★ per turn over a human, not +4; bots probably omniscient; Crazy-brain/Normal-income possible (rules, strategy) | major | **Accepted.** Docs corrected; M0 bot checks |
| 17 | Diplomacy live in 1v1; siege, connections, embassy tech-price multiplier missing (rules) | major | **Accepted.** In scope-and-rules; features added (besieged, connected) |
| 18 | Opening is critical; threats unfold over 2 turns; reachability feature (rules) | major | **Accepted.** Openings always critical; derived reachability input |
| 19 | Live clock: 8 s + 12 s/city + 1 s/pop, time banks, auto-skip (rules) | major | **Accepted.** Clock feature, replay truncation detection |
| 20 | Human data speculative: needs an authenticated client; hundreds of games, not 30k (strategy) | major | **Accepted.** Timeboxed spike; never blocks a milestone; test set first |
| 21 | Intent head can't express coordination or Escape/Persist; self-distillation narrows search (ML, rules) | major | **Deferred**, with a redesign note |
| 22 | Value ensemble on a shared trunk understates uncertainty (ML) | minor | **Deferred**; randomized priors if needed |
| 23 | Draw cap teaches stalling (ML) | minor | **Accepted.** Capped games dropped from the value loss or adjudicated |
| 24 | Symmetry augmentation (8×) missing (ML) | minor | **Accepted, gated** on a rule-invariance check |
| 25 | Replay buffer, versioning, ops under-specified (systems) | major | **Accepted.** Sample window, replay ratio, version tags, watchdog, checkpoints |
| 26 | "Game UI data" invariance test not implementable (systems) | minor | **Dropped** |
